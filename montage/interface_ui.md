# Éléments d'interface à créer une fois

Crée-les une seule fois en pixel, puis réutilise-les dans tous les épisodes :
- Boîte de dialogue pixel (fond bleu foncé, bord blanc) + police pixel (ex. *Press Start 2P*, gratuite)
- Barre d'XP (bas de l'écran)
- Cœurs de vie de Sami (haut gauche)
- Barre de vie du boss (haut, violet)
- Pop-ups « +XP », « Statut », « BOSS VAINCU », « COMBO »
- Écran de chargement + jingle d'intro
- Écran de fin + jingle d'outro


## Éléments du format POV interactif
- **Badge de contexte** en haut à gauche : cadre pixel noir semi-transparent, 💾 + lieu · date · « Sami, Niv. X ».
- **Pop-ups « pigeon »** : façon notification de téléphone, mais en parchemin pixel avec une icône 🕊️.
- **Écrans « X JOURS PLUS TARD »** : fond noir, texte pixel blanc, petit bruit de chargement.
- **Écran de choix A/B** : deux boutons pixel vert et rouge, à laisser 3 à 4 s à l'écran.
- **Carte FAIT RÉEL** : fond parchemin, texte sobre, aucune blague.
- **Sous-titres** : mot par mot, centrés, police pixel, mots-clés en jaune.
