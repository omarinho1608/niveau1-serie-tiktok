1. Dans ton dossier de montage habituel (celui de l'Ankou, avec ton `SUIVI.md`), crée un sous-dossier **`ep02_aicha`**.
2. Dedans, crée **`clips`** et mets-y **une copie** de tes 17 clips, nommés **`D01.mp4` à `D17.mp4`**.
3. *(Optionnel)* **`sons`** : `fete.mp3` (musique de mariage marocain libre de droits), `eau.mp3`, `grenouilles.mp3`, `cri.mp3`, `musique.mp3` (drone sombre).
4. Ouvre ta session Claude Code **dans le dossier de montage habituel** (pas dans `ep02_aicha`), pour qu'il garde ton `SUIVI.md`, et colle le bloc ci-dessous.
