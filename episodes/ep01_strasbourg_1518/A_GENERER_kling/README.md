## Pour chaque scène, c'est toujours la même routine
1. **Étape 1 :** génération d'image avec le décor et l'Element, puis le prompt « image clé ».
2. Vérifie : le perso ressemble à sa référence, le style pixel est identique au décor.
3. **Étape 2 :** Image-to-Video avec l'image clé, le prompt « animation » et les réglages du tableau.
4. Enregistre le clip sous le nom indiqué en bas du fichier.

## Ce qui ne se génère PAS dans Kling (montage)
Le badge de lieu et de date, la notification pigeon, les écrans « X JOURS PLUS TARD », l'écran de choix A/B, la carte « FAIT RÉEL ». Voir `../../../montage/interface_ui.md`.
