# 0. Elements à créer AVANT les scènes

Deux nouveaux personnages ont besoin d'un **Element** dans la bibliothèque Kling (comme Sami et Bernard). Fais-le en premier.

## Comment faire (rappel)
1. Génère la **fiche personnage** avec le prompt ci-dessous (génération d'image, format 1:1 ou 16:9).
2. Garde la meilleure image et découpe-la : **1 image de face** (principale) + **1 de profil**.
3. Kling → **Element Library** → nouvel Element **personnage** → image principale = face, image supplémentaire = profil.
4. Nomme-le exactement : `Greta` / `FrauTroffea`.
